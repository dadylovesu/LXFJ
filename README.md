
# 本分支为本地代理方式运行。本地运行项目，其它电脑通过局域网访问使用，其它电脑无需使用VPN


# 通过VPN代理部署，让**你开启VPN**，其他用户**无需VPN**即可正常使用AI功能。


### IP配置
全局替换IP为你的IP

### 手动启动
```bash
# 终端1：启动前端
npm run dev

# 终端2：启动后端
cd server 
npm start
```

### 代理配置 (server/env.config)

根据你的VPN/代理软件修改端口：

```env
# Clash 默认端口 (推荐)
HTTP_PROXY=http://127.0.0.1:7890
HTTPS_PROXY=http://127.0.0.1:7890

# V2Ray 默认端口
HTTP_PROXY=http://127.0.0.1:10809
HTTPS_PROXY=http://127.0.0.1:10809

# 系统VPN（全局模式）
# 如果开启全局VPN，注释掉上面的两行
```

### 端口配置

- **前端**: `http://192.168.10.48:3000` (已配置)
- **后端**: `http://192.168.10.48:3001` (已配置)


### 分享给其他用户
其他用户直接访问 `http://192.168.10.48:3000` 即可使用，无需开启VPN。


### 网络连接问题
- 确保防火墙允许3000和3001端口
- 检查本地网络设置
- 验证IP地址 `192.168.10.48` 是否正确
